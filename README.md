## Folder Purpose

- `src/` — Contains the main source files of the website.
- `src/assets/` — Contains static assets used by the website.
- `src/assets/images/` — Stores images such as product images, logos, and other graphics.
- `src/css/` — Contains CSS files used for styling and layout.
- `src/js/` — Contains the JavaScript code.
- `src/js/components/` — Contains reusable JavaScript components.
- `src/js/mocks/` — Contains mock data used for development and testing.
- `src/pages/` — Contains the different pages of the website.
- `index.html` — Main entry point of the website.
- `.gitattributes` — Contains Git file-handling configuration.
